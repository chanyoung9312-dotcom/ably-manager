# 소싱 신호 12단계 — 후보 근거 상품 드릴다운

## 목적

11단계의 품목 단위 후보 분류에서 한 단계 더 내려가, **어떤 기존 상품들이 해당 신호를 만들었는지** 확인할 수 있게 한다.

이 단계도 추천 점수나 사입 행동을 추가하지 않는다. 상품 근거는 이미 `sourcing-signals`에서 계산된 productStats를 읽어 보여주는 용도다.

## 데이터 흐름

`loadDashboard → sourcing-live → sourcing-signals → sourcing-candidates → sourcing-evidence → sourcing-candidate-view → /sourcing`

`sourcing-evidence`는 기존 productStats를 투영하며 Q/N/E를 다시 계산하지 않는다.

## 근거 상품 표시

후보 카드 안의 `근거 상품 보기`에서 주문 반응을 만든 상품만 표시한다.

각 상품에는:

- 상품명
- 상품번호
- 누적 주문 Q
- 순판매 N
- 판단 반영 E
- 최근30일 주문 Q
- 주문일 수

를 보여준다.

역할 태그:

- TOP1 기여 상품
- TOP2 기여 상품
- 다른 날짜 반복
- 판단 반영 반복
- 최근 30일 반응
- 다른 그룹과 근거 공유

## 상품명 연결

상품명은 MD catalog의 `productNo`로 연결한다.

- 하나의 이름으로 연결되면 그대로 표시
- catalog에 없으면 상품번호만 표시
- 동일 상품번호에 서로 다른 상품명이 있으면 임의로 하나를 고르지 않고 `상품명 확인 필요`로 표시

상품명 연결 실패가 후보 lane을 바꾸지는 않는다.

## 개인정보

근거 상품 출력에는 주문번호, 상품주문번호, 고객명, 전화번호, 주소 등 주문자 정보가 포함되지 않는다.

## 해석 원칙

근거 상품 목록은 “이 상품을 다시 사라”는 의미가 아니다.

특히 `hit_reference`에서는 상위 상품이 왜 카테고리 전체 성과를 대표할 수 없는지 확인하기 위한 자료다.

예:

- 롱원피스 TOP1 상품 Q=113
- TOP2 상품 Q=63
- 두 상품 합계 176/178

이 구조를 사용자에게 직접 보여줘 소수 히트 의존을 확인할 수 있게 한다.

## 금지 사항

- 추천 점수
- 상품별 추천 순위
- 재주문 수량
- 자동 발주
- 상품 경쟁력 점수
- 고객 정보 노출
- 기존 Q/N/E 재계산
- candidate lane 변경
