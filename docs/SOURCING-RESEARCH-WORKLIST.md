# 소싱 신호 16단계 — 소싱 조사 작업목록

## 목적

13단계의 소싱 검토 브리프를 실제 공급처 조사 단계로 넘기기 위한 **읽기 전용 작업목록**을 만든다.

이 단계는 어떤 상품을 사라고 결정하지 않는다. 대신 소싱 검토 후보가 생겼을 때 사람이 공급처에서 무엇을 확인하고 기록해야 하는지 빠짐없이 정리한다.

## 대상

작업목록의 입력은 `review_candidate`에서 생성된 소싱 검토 브리프다.

따라서:

- 히트 구조 참고
- 추가 관찰
- 데이터 보류

는 조사 작업으로 자동 승격하지 않는다.

## 작업 카드

각 품목 카드에는 다음을 보여준다.

### 현재 관측 근거

- 반응 상품 수
- 다른 날짜 반복 상품 수
- 최근 30일 활성 상품 수

### 조합 관측 맥락

기존 조합 상태를 그대로 보존한다.

- 반복 근거 확인
- 초기 관측
- 특정 상품 근거
- 데이터 보류

반복 근거가 없는 경우 `현재 확인된 조합 없음`을 명시한다.

### 공급처 조사 필드

필수:

- 공급처 링크
- 공급가
- 공급처 배송기간
- 색상·사이즈 옵션

선택:

- 소재·상세정보
- 비교 메모

### 기존 근거 상품

현재 후보를 만든 기존 상품을 최대 3개 참고용으로 표시한다.

기존 상품과 비슷하다는 이유만으로 신규 공급처 상품을 자동 통과시키지 않는다.

## 복사용 조사 템플릿

각 작업 카드에는 사람이 타오바오/1688 등에서 상품을 확인한 뒤 붙여 넣어 기록할 수 있는 텍스트 템플릿을 제공한다.

예:

```
[소싱 조사] 숏·하프팬츠
반복 근거 확인: 현재 확인된 조합 없음
초기 관측: 숏·하프팬츠 ∩ 데님

공급처 링크:
공급가:
공급처 배송기간:
색상·사이즈 옵션:
소재·상세정보:
비교 메모:
```

## 저장

16단계에서는 아직 저장하지 않는다.

`persistence = none`

이다.

이유는 현재 Google Sheet에 공급처 후보를 저장할 전용 원장 계약이 없기 때문이다.

기존 MD 시트의 자유 공간에 임의로 쓰거나, 새 탭을 자동 생성하거나, 공급처 후보를 기존 상품으로 간주해서는 안 된다.

## 다음 단계의 영속 원장 계약

저장 기능을 만들려면 먼저 전용 원장의 다음 항목을 확정해야 한다.

- source candidate ID
- 조사 대상 품목/group ID
- 공급처 URL
- 공급가
- 배송기간
- 옵션
- 소재/메모
- 조사일
- 상태
- 실제 상품 등록 후 연결할 productNo

그리고 신규 후보의 상태 이력을 보존할지, 수정형 최신값만 보존할지도 결정해야 한다.

## 금지 사항

- 공급처 자동 순위
- 신규 상품 자동 추천 점수
- 사입 수량
- 자동 구매
- 초기 관측을 반복 근거로 승격
- 외부 시장 수요 추정
- 기존 MD 상품으로 자동 생성
